# douyin-extractor-guide

`douyin-image-extractor` 的公开配套仓库：功能说明、安装与使用指南、常见问题、更新日志。

主仓库：https://github.com/adigailmichael19-art/douyin-image-extractor

## 它是什么

一个运行在 Windows 上的抖音图文提取工具，Tkinter 图形界面，支持批量提取图文作品的原图与视频，仓库内含测试与桌面启动器。

## 适合谁

- 需要把已发布的图文作品原图、视频存档备份的创作者
- 做素材整理、需要批量落盘的运营同学

## 快速开始

1. 打开主仓库，按其中 README 的说明获取程序与依赖
2. 运行桌面启动器，或在源码目录执行入口脚本
3. 粘贴作品链接、选择输出目录，开始批量提取

> 具体的安装命令、参数与界面截图以主仓库为准；本仓库只做说明与索引，避免两处描述不一致。

## 常见问题

**Q：提取失败或只拿到部分图片？**
先确认作品链接可公开访问，再检查输出目录是否可写；仍失败时保留日志，在主仓库提 Issue。

**Q：支持视频吗？**
支持，图文作品中的视频会一并下载，具体格式与命名以主仓库说明为准。

**Q：会用到账号 Cookie 吗？**
按主仓库的权限说明为准；本仓库不保存任何账号凭据。
